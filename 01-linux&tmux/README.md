# 🐧 ДЗ #01: Linux & Tmux — Управление веб-серверами

---

## 📋 Условие задачи

Необходимо написать консольную программу `homework`, которая управляет набором запущенных копий веб-приложения на Python (`server.py`). Программа должна работать с tmux-сессиями, создавать бэкапы и собирать результаты работы серверов.

---

**Функционал вашей программы**
1. Запустить новую копию веб-сервера
```shell
./homework start --name <server_name> --port <server_port>
```
где:
- `<server_name>` — уникальное имя новой копии сервера;
- `<server_port>` — порт, на котором нужно запустить новую копию сервера.
Уникальное имя состоит исключительно из букв в нижнем регистре длиной от 1 до 32 символов.
Запуск новой копии сервера состоит в следующем:
1. Создать в текущей папке новую папку с именем `<server_name>`.
2. Скопировать в созданную папку файл веб-приложения `server.py`. Он будет находиться в той же директории, из которой будет запускаться ваше приложение.
3. Запустить копию веб-приложения **в созданной папке внутри tmux-сессии с именем `homework` в отдельном tmux-окне** с именем `<server_name>` следующим образом:
```shell
python server.py --port <server_port>
```

Копия должна быть запущена именно из своей папки!

4. **stdout** процесса сервера нужно перенаправить в файл `out.txt` в созданной папке — это будет результатом работы веб-приложения.
Примечание: порядок аргументов `--name <server_name>` и `--port <server_port>` может быть произвольный.

**Для продвинутого потока**

Дополнительно нужно реализовать проверки:
1. Если существует копия сервера с именем `<server_name>` — `exitcode 1`.
2. Если существует копия сервера с портом `<server_port>` — `exitcode 2`.
3. Если порт `<server_port>` занят процессом, отличным от сервера — `exitcode 3`.
4. После выполнения команды для запуска копии сервера подождать 3 секунды и проверить его работоспособность с помощью запроса:
```
http://localhost:<server_port>/healthcheck
```
