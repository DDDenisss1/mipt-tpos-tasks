## 🎓 Чему я научился

Выполнение этого задания дало мне глубокое практическое понимание управления процессами и автоматизации в Linux. Вот ключевые навыки, которые я приобрел:

### 🔷 Архитектура CLI-приложений

- Научился проектировать **консольные утилиты** с подкомандами (`start`, `stop`, `stop_all`, `collect_all`)
- Освоил парсинг аргументов командной строки с помощью `argparse` (флаги `--name`, `--port`, `--zip`)
- Понял важность **идемпотентности** операций (повторный вызов `stop` не ломает систему)
- Реализовал валидацию входных данных (имя сервера: только lowercase буквы, 1–32 символа)

### 🔷 Работа с Tmux программно

- Научился управлять **tmux-сессиями** и **окнами** через CLI (`tmux new-session`, `new-window`, `kill-window`, `kill-session`)
- Освоил отправку команд в tmux-окна (`tmux send-keys` с `Enter`, `C-c` для Ctrl+C)
- Понял разницу между сессией, окном и панелью в tmux
- Реализовал именование окон по имени сервера для удобной навигации

### 🔷 Управление процессами в Linux

- Научился запускать процессы в фоне с перенаправлением `stdout` в файл (`> out.txt`)
- Освоил поиск и завершение процессов по порту (`fuser -k <port>/tcp`)
- Понял важность **корректного завершения** процессов (сначала `Ctrl+C`, потом принудительное убийство)
- Реализовал проверку занятости порта через `socket.connect_ex()`

### 🔷 Работа с файловой системой

- Научился создавать и удалять директории программно (`mkdir`, `shutil.rmtree`)
- Освоил копирование файлов между директориями (`shutil.copy`)
- Реализовал систему **backup** с timestamp (`out_<name>_<timestamp>.txt`)
- Понял важность разделения данных и кода (каждый сервер в своей папке)

### 🔷 HTTP-запросы и health checks

- Научился делать HTTP-запросы из Python (`urllib.request.urlopen`)
- Реализовал проверку работоспособности сервера через `/healthcheck` endpoint
- Освоил обработку HTTP-ошибок (`urllib.error.HTTPError`) и таймаутов
- Понял важность **grace period** (ожидание 3 секунды перед проверкой)

### 🔷 Обработка ошибок и exit codes

- Реализовал систему кодов возврата для разных сценариев ошибок:
  - `exitcode 1` — сервер с таким именем уже существует
  - `exitcode 2` — порт уже используется другим сервером
  - `exitcode 3` — порт занят системным процессом
  - `exitcode 4` — server не прошёл healthcheck
- Научился выводить понятные сообщения об ошибках в `stderr`

### 🔷 Сбор и агрегация данных

- Научился читать содержимое файлов и выводить их в отсортированном виде
- Освоил работу с **ZIP-архивами** через модуль `zipfile` (для продвинутого потока)
- Реализовал форматированный вывод с разделителями (`=== server: <name> ===`)
- Понял важность лексикографической сортировки для предсказуемого результата

### 🔷 Bash-скриптинг и автоматизация

- Написал `install.sh` для автоматической установки зависимостей (`apt-get install`)
- Освоил работу с системными пакетами (`tmux`, `psmisc`, `zip`, `curl`)
- Научился использовать `set -e` для остановки скрипта при ошибке
- Понял важность идемпотентности установочных скриптов

### 🔷 Python для системного программирования

- Научился работать с `subprocess.run()` для выполнения shell-команд
- Освоил модули `pathlib` (объектно-ориентированная работа с путями)
- Реализовал проверку существования файлов и директорий (`Path.exists()`)
- Научился работать с **Unix timestamp** для уникальных имён бэкапов
- Освоил перенаправление потоков (`1>&2`, `2>&1`) на уровне Python

### 🔷 DevOps-мышление

- Понял важность **воспроизводимости** (любой может запустить `./homework` и получить тот же результат)
- Научился разделять **код** (`homework`), **данные** (папки серверов) и **результаты** (`.backup/`)
- Освоил создание **самодокументирующегося кода** (понятные имена функций, комментарии)
- Реализовал **graceful degradation** (если tmux-сессии нет — создаём, если есть — используем)
